# Kit de redes sociales · Santos Saucedo

## Contenido
- `Catalogo Redes Sociales (offline).html` muestra todas las piezas en un solo archivo, sin necesidad de internet.
- `plantillas/posts/` contiene 13 posts individuales en HTML editable.
- `plantillas/carruseles/` contiene 13 carruseles de 4 diapositivas en HTML editable.
- `assets/` reúne logos, el símbolo SS, la foto del socio e íconos.
- `componentes.js` es la librería de componentes (objeto `SS`) para crear piezas nuevas.
- `generador.html` es un ejemplo de uso de `componentes.js`.
- `SISTEMA-DE-DISENO.md` explica colores, tipografía, retícula, componentes y la regla de fotos.
- `SKILL.md` tiene las instrucciones para que un asistente de IA genere piezas nuevas con este sistema.

## Cómo editar una plantilla
1. Abre el `.html` en el navegador para verla.
2. Edita el texto directamente en el código.
3. Las fotos pendientes aparecen como recuadros grises `data-foto`. Reemplázalos por `<img>` con `object-fit:cover`. **No apliques filtros de color a las fotos.**
4. Exporta cada cuadro de 1080 × 1080 como PNG (captura de pantalla del elemento o con la herramienta de diseño).
