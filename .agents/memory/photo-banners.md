---
name: Cabeceras principales
description: Decisión vigente sobre las imágenes en los banners de las páginas principales.
---

Después de explorar el estilo fotográfico de Oficinas y rechazar las imágenes repetidas, el usuario decidió: «quita las imagenes mejor».

**Why:** El usuario cambió su decisión; esta indicación sustituye la propuesta anterior de generar imágenes nuevas para los banners.

**How to apply:** Mantener las cabeceras de las páginas principales sin fotografías. No generar imágenes sustitutas ni volver a reutilizar imágenes de oficinas como fondos. Esta petición se refiere a los banners añadidos, no a los retratos de socios ni a las fotografías del contenido. La portada y la página original de Oficinas no forman parte de este cambio.
