---
name: Fotos de Prácticas
description: Coincidencia requerida entre las fotografías de Prácticas y las del inicio.
---

El directorio de Prácticas debe mostrar las mismas fotografías que el inicio, respetando la asociación de cada práctica.

**Why:** Después del rediseño, el usuario corrigió expresamente: «no pusiste ls mismas fotos que las del inicio».

**How to apply:** Tomar las fotografías aprobadas visibles en el inicio como referencia al trabajar el directorio; no seleccionar imágenes diferentes por separado ni cambiar el inicio para hacerlo coincidir con fotos que el usuario no pidió.
