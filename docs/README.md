## Documentos históricos

Los documentos con fecha de julio y octubre conservan decisiones, evidencia y antecedentes. No son instrucciones vigentes por defecto. Antes de usarlos, confirma que la carpeta, el runtime, las rutas y el commit todavía coinciden con [ARCHITECTURE.md](ARCHITECTURE.md).

Entre los documentos históricos están los de paridad CMS, pruebas de agentes, localización, investigación inicial, handoff y el contexto antiguo de GitHub Pages.

## Regla de estado documental

Cada documento operativo debe indicar fecha de corte, commit, entorno y propietario. Cada evidencia de prueba debe indicar comando, URL, navegador, viewport, resultado y si fue local, Replit o Pages.
